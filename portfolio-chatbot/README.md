# Ask Rutaab — portfolio chatbot

Drop-in Groq chatbot for the static Vercel portfolio.

**Start here:** [SETUP.md](./SETUP.md)

- Frontend widget: `js/chatbot.js` + `css/chatbot.css` (no API key)
- Serverless proxy: `api/chat.js` (reads `GROQ_API_KEY`)
- Ground truth: `lib/portfolio-knowledge.js` (answers stay inside the site)
